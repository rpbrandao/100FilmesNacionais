# 100 Filmes Nacionais

Aplicação web com os 100 maiores filmes brasileiros indicados por críticos.

## Funcionalidades

- **Lista completa** dos 100 filmes com ranking, ano, gênero e nota
- **Filtro por gênero**: Drama, Comédia, Crime, Aventura, Animação
- **Busca** por título, diretor ou sinopse
- **Ordenação** por ranking, ano, título ou nota
- **Dois modos de visualização**: grade e lista
- **Modal de detalhes** com sinopse completa, elenco e informações do filme
- **Seção de destaques** com os 5 melhores filmes em destaque
- Design editorial responsivo inspirado em pôsteres de cinema

## Como usar

Abra o arquivo `index.html` diretamente no navegador — sem servidor, sem dependências.

## Estrutura

```
100FilmesNacionais/
├── index.html   # Estrutura HTML
├── style.css    # Estilos (tema editorial cinema)
├── data.js      # Dados dos 100 filmes
├── app.js       # Lógica da aplicação
└── README.md
```

## Tecnologias

- HTML5 semântico
- CSS3 com variáveis customizadas
- JavaScript vanilla (sem frameworks)
- Google Fonts: Playfair Display + DM Sans

## Curadoria

Os filmes foram selecionados com base nas listas da Abraccine (Associação Brasileira de Críticos de Cinema) e outras publicações especializadas em cinema nacional.
